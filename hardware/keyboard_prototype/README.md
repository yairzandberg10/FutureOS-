# FutureOS Keyboard Prototype - מה יש כאן ואיך מזמינים

אב-טיפוס USB של מקלדת FutureOS: ‏21 מקשים, מטריצה 5×5 ותאורה אחורית. הלוח נשלט על ידי XIAO RP2040 **לבדיקה בלבד**, וה-XIAO אינו חלק מהחומרה הסופית של FutureOS Regular.

## הקבצים

| קובץ | מה זה |

## הזמנה מ-JLCPCB (10 לוחות)

1. ב-jlcpcb.com בוחרים **Order now** ומעלים את `fab/keyboard_prototype_gerbers.zip`.
2. בוחרים את ההגדרות: 2 שכבות, **עובי 1.0 מ"מ**, כמות 10, וכל השאר בברירת מחדל.
3. מסמנים **PCB Assembly**, צד **Top**, ומעלים את `BOM_JLCPCB.csv` ואת `CPL_JLCPCB.csv`.
4. במסך ה-preview בודקים שכל רכיב יושב על הפדים שלו. **כדאי לבדוק במיוחד את כיוון הדיודות והנורות.** אם משהו מסובב, מתקנים את הסיבוב שם, בממשק של JLC.
5. את ה-XIAO RP2040 קונים בנפרד (Seeed, כ-5 דולר ליחידה). המפעל לא מרכיב אותו.

## הרכבה ידנית (אחרי שהלוחות מגיעים)

1. **ה-XIAO**: מולחם שטוח בצד האחורי, כשהרכיבים שלו פונים החוצה וה-USB-C פונה לקצה התחתון, בהתאם לסימון ה-"USB-C" על הלוח. מלחימים רק את 14 הפדים שבצדדים, ולא את הפדים שמתחתיו.
2. **JP1**: מחברים את שני חצאי הגשר בטיפת בדיל. בלי זה התאורה לא תדלק מה-USB.
3. **J1 (FPC)** לא נדרש לבדיקה עם ה-XIAO. **לא מחברים כבל FPC כשה-XIAO מולחם.**

## הפעלה

1. מחזיקים את כפתור BOOT ב-XIAO ומחברים אותו למחשב. מופיע כונן בשם RPI-RP2.
2. גוררים לכונן קובץ UF2 של CircuitPython ל-XIAO RP2040 מאתר circuitpython.org. אחרי זה מופיע כונן בשם CIRCUITPY.
3. מעתיקים לכונן את `firmware/boot.py` ואת `firmware/code.py`, ומנתקים ומחברים מחדש.
4. במכשיר Android עם root, מתקינים את `firmware/Vendor_1209_Product_0001.kl` לפי ההוראות שבראש הקובץ.
5. מחברים את המקלדת לטלפון דרך OTG.

## מה לבדוק (תכתוב לי את התוצאות)

- התאורה נדלקת בלחיצה ונכבית אחרי 8 שניות.
