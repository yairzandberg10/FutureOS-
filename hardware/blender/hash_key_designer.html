מעצב מקש #

המקש # של הגוף החלופי v3 ל-Qin F22 Pro יושב צמוד למצלמת הסלפי. בוחרים צורה (גלולה עם העדשה לפי הפיגמה, קשת, גלולה נפרדת או עגול), מידות, עיגול שפה, גופן וסיבוב של הסימון, והשרטוט והבדיקות מתעדכנים בקנה מידה אמיתי, במ"מ. בסוף מעתיקים את ה-JSON לקובץ hardware/blender/hash_key.json או שולחים אותו בצ'אט, והסקריפט בונה את המקש לפיו.
