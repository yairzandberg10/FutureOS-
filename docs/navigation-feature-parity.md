# ניווט: רשימת הפיצ'רים של Moovit, אגד ו-Waze

רשימת העבודה של אפליקציית Navigation (`apps/Navigation`) מול שלוש האפליקציות.
כל פיצ'ר נבנה בקוד שלנו ובממשק שלנו (מקשים בלבד, 640×960). החישובים רצים בשרת (`server/feedback`), והמכשיר לא מוריד את קובץ ה-GTFS הארצי.

סימנים: ✅ בוצע · 🟡 חלקי · ⬜ עוד לא · ⛔ לא אפשרי במכשיר הזה

## Moovit (תחבורה ציבורית)

| פיצ'ר | מצב | הערות |
|---|---|---|
| תכנון מסלול בשרת, בלי הורדת GTFS | ✅ | `POST /v1/nav/transit` (HERE Public Transit) |
| תחנות קרובות עם זמני יציאה חיים | ✅ | `POST /v1/nav/departures`, מסך הבית במצב תחבורה ציבורית |
| שעות זמן אמת על קטע הנסיעה (SIRI) | 🟡 | רק במסלולים מהתכנון המקומי. למסלולים מהשרת אין מזהה תחנה של משרד התחבורה |
| התראת "רדו בתחנה הבאה" | ✅ | במסך המסלול: קול, רטט והודעה 500 מ' לפני תחנת הירידה. המסך לא נכבה |
| ניווט צעד-אחר-צעד לאורך מסלול תחבורה | ⬜ | |
| חיפוש קו לפי מספר ולוח הזמנים שלו | ⬜ | |
| תחנות וקווים מועדפים | ⬜ | |
| התראות שיבושים ושינויי קווים | ⬜ | |
| מיקום האוטובוס על המפה | ⬜ | SIRI VehicleMonitoring |
| קורקינטים/אופניים שיתופיים | ⬜ | |
| תשלום נסיעה (רב-קו) | ⛔ | אין NFC ותשלום במכשיר. דורש הסכם עם מפעיל |

## מה לא נבדק

- כל מה שמסומן ✅ מקומפל ונבדק ביחידה (שרת: `npm test`, אפליקציה: `TransitServerPlannerTest`), אבל לא נבדק על המכשיר.
- כיסוי HERE לתחבורה הציבורית בישראל לא אומת מול קריאה אמיתית. אם השרת מחזיר מסלול ריק והנתונים המקומיים כבר מכסים את האזור, האפליקציה מנסה גם אותם.
