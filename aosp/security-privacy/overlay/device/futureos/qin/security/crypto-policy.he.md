# מדיניות קריפטוגרפית של FutureOS (אנדרואיד 12)

**מצב: טיוטה.** שורות עם [לאימות] דורשות בדיקה על המכשיר.

| תחום | מה בשימוש | הערה |
|-|-|-|
| ספרייה מערכתית | BoringSSL ו-Conscrypt (מ-AOSP) | מתעדכנות עם גרסאות המערכת |
| הצפנת אחסון | File-Based Encryption, AES-256-XTS | Adiantum אם אין האצת AES [לאימות בשבב] |
| מפתחות | Android Keystore (KeyMint בחומרה המאובטחת של השבב) | המפתחות אינם ניתנים לייצוא. אין TPM במכשיר |
| TLS | 1.3 ו-1.2 | האם 1.0/1.1 כבויים בברירת מחדל: [לאימות] |
| מחיקת נתונים | איפוס יצרן מוחק את מפתחות ההצפנה | דורש /metadata תקין |
| ביטול תעודות | אין בדיקת OCSP/CRL גורפת | פער ידוע של אנדרואיד 12 |
| רשימת רשויות תעודה | חלק מ-ROM, מתעדכנת רק בעדכון מערכת | בלי OTA הרשימה קפואה |
| Passkeys / WebAuthn | לא נתמך במערכת בגרסה 12 | נדרש רכיב נוסף |
| גיבוי | אין גיבוי ענן. כל גיבוי עתידי חייב להיות מוצפן | |
