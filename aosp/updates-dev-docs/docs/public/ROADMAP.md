# מפת דרכים (סעיף 994)

טיוטה לפרסום פומבי. מבוססת על לוח הזמנים ב-`docs/aosp-port-plan.md` סעיף 6. התאריכים הם הערכות, לא התחייבויות. אין בה כלום שנבדק על מכשיר.

| אבן דרך | מה | תנאי מעבר |
|---|---|---|
| M0 | גיבוי ו-dump של המכשיר, ניתוח המחיצות (A/B?) | גיבוי מאומת בשני מקומות |
| M1 | ROM עולה: מסך, מקלדת, ADB | boot ל-launcher וכל המקשים מגיבים |
| M2 | רדיו: שיחות, SMS, נתונים, VoLTE בישראל | שיחה של 10 דקות בשני ספקים |
| M3 | FutureUI כ-System UI, FutureLauncher כ-HOME, בלי root | כל האפליקציות עוברות smoke test |
| M4 | מצלמות, חיישנים, IR, תאורת מקלדת, אודיו | רשימת הבדיקות של `device-qa` |
| M5 | build חתום, AVB, OTA ראשון | OTA אינקרמנטלי בלי מחיקת נתונים |
| M6 | יציבות: 7 ימים של שימוש יומיומי | אין קריסת רדיו או System UI |

## אחרי M6 (רעיונות, לא התחייבות)
FutureBackup (כרטיס SD), ערוץ push, גרסה יציבה ראשונה לציבור, מסך מוניטור ב-Tools.

## מי מעדכן
מעדכנים בכל סגירת אבן דרך. סימון "הושלם" מותנה במבחן המעבר.
