# מחזור חיים ותמיכה (סעיפים 826, 827, 828)

**זו הצעה בלבד.** תמיכה לטווח ארוך היא התחייבות עסקית ואין לפרסם אותה בלי החלטה של בעל הפרויקט. ה-overlay אינו מגדיר תאריכים (`futureos_lifecycle.mk`, השורות מושבתות בהערה).

## עובדות שמגבילות
- הבסיס המתוכנן הוא LineageOS 19.1 (Android 12L). לפי ידיעתי בסיס זה אינו מקבל תחזוקה פעילה מ-upstream (לבדוק מצב עדכני), כך שתיקוני אבטחה של Android 12 יהיו תלויים ביכולת שלנו לשלב אותם (backports מ-Android Security Bulletins).
- הקרנל הוא prebuilt של היצרן עד שמתקבל קוד GPL (aosp-port-plan סעיף 1ב). אי אפשר לתקן CVE בקרנל בלי מקור.
- ה-blobs של MediaTek קפואים לגרסת ה-vendor.
- **המסקנה:** התחייבות של 5 שנים (827) היא בעייתית כרגע.

## שלבי חיים (הצעה)

## הודעה על סוף תמיכה (828)
הצעה: הודעה במסך העדכון ובהערות הגרסה **לפחות 180 יום** לפני סוף התמיכה בגרסה. מאפיינים: `ro.futureos.eol_notice_days` ו-`ro.futureos.security_support_until` (מוצג ב"אודות").
