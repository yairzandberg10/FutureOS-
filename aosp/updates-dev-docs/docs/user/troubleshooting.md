# פתרון תקלות (סעיף 990)

> סטטוס: טיוטה. הטבלה נבנית מהסיכונים ב-`aosp-port-plan.md` ומ"בעיות ידועות". תוסף כאן כל תקלה חוזרת שמגיעה מהמשוב.

| תקלה | מה לעשות |
|---|---|
| המכשיר לא עולה אחרי עדכון | להמתין עד 10 דקות (האתחול הראשון איטי). אחר כך לכבות ולהדליק. אם עדיין תקוע: מצב בטוח (OK או תפריט בזמן האתחול). במכשיר עם A/B הוא יחזור לגרסה הקודמת לבד אחרי כמה ניסיונות |
| אפליקציה קורסת או נתקעת | לצאת ולפתוח שוב. אם חוזר: הגדרות > אפליקציות > נקה נתונים (מוחק נתוני האפליקציה). אפשר לשלוח משוב עם הדוח |
| הממשק איטי או נתקע | להפעיל מחדש. לבדוק אחסון פנוי (פחות מ-10% מאט את המכשיר) |
| שכחתי PIN | אין שחזור. נדרש איפוס מלא (מחיקת כל הנתונים) |
| אחסון מלא | הגדרות > אחסון, למחוק קבצים גדולים, או להעביר לכרטיס |
| אין עדכונים | לבדוק חיבור לרשת. הערוץ (dev/beta/stable) מוצג ב"אודות" |
| אין שיחות | **בישראל אין 3G**, ושיחות דורשות VoLTE. אם הסימון VoLTE לא מופיע, לפנות לתמיכה עם מספר ה-build |
| התראות הודעות לא מגיעות | אין שירותי Google. ההתראות עוברות בערוץ של FutureOS ודורשות רשת **[ר' "בעיות ידועות"]** |
| המכשיר לא מגיב לכפתורים | להחזיק את כפתור ההפעלה לכיבוי כפוי **[משך ההחזקה: לאמת במכשיר]** |

## איסוף מידע לדיווח
הגדרות > שלח משוב. תראו בדיוק מה ישלח לפני אישור. ללא אינטרנט, המשוב נשמר ויישלח כשיחזור החיבור.
