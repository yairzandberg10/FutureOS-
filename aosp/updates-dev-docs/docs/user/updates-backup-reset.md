# עדכונים, גיבוי ואיפוס - למשתמש (סעיפים 817, 838, 839, 923-928, 955)

> סטטוס: טיוטה. גיבוי דורש את אפליקציית FutureBackup **[מתוכנן, עדיין לא נכתבה]**.

## לפני שמתחילים
כרטיס SD (או התקן USB שנתמך) הוא מקום הגיבוי היחיד בגרסה הראשונה. אין גיבוי לענן.

## מה מתגבה
| מה | איך משוחזר |
|---|---|
| הגדרות המערכת (שפה, בהירות, צלילים ועוד) | אוטומטית באשף ההפעלה אחרי איפוס |
| נתוני אפליקציות (אנשי קשר, פתקים, משימות, הודעות לפי האפליקציה) | באשף ההפעלה |
| קבצים אישיים (תמונות, מסמכים, מוזיקה) | כקבצים רגילים בכרטיס: אפשר להעתיק קובץ בודד בלי שום כלי |
| PIN ותבנית הפנים | **לא מתגבים** (ליתר ביטחון). יש להגדיר מחדש |

## איפוס להגדרות יצרן
הגדרות > איפוס. מוחק את **כל** מה שבזיכרון הפנימי. אי אפשר לבטל.
1. גבו לכרטיס.
2. ודאו שהגיבוי הושלם והעתיקו תמונות חשובות ידנית בנוסף.
3. אשרו איפוס. אחרי האתחול, אשף ההפעלה מציע שחזור מהכרטיס.

### "איפוס ושמירת הקבצים"
בגלל ההצפנה במכשיר אי אפשר לשמור קבצים בזיכרון הפנימי בזמן איפוס: מפתח ההצפנה נמחק. הדרך הבטוחה היחידה היא לגבות לכרטיס, לאפס, ולשחזר.

## אחרי עדכון מערכת
הנתונים לא נמחקים בעדכון רגיל. אם העדכון נכשל, המכשיר חוזר לגרסה הקודמת **[תלוי במכשיר, ר' "בעיות ידועות"]**.
