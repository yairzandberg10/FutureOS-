# צ'קליסט למשתמש לפני שלב M0 (בלי מחשב, 5 דקות)

מה לבדוק בטלפון לפני שמריצים סקריפט כלשהו. כתוב את התשובות ושלח אותן לצ'אט.

## 1. גרסת הקושחה (הכי חשוב)
**הגדרות ← אודות הטלפון ← מספר Build / גרסת תוכנה.** רשום את הגרסה המלאה.
- **1.0.x:** ה-bootloader כנראה נפתח רגיל.
- **1.1.0 ומעלה:** לפי פורום Hovatek, Qin חסמו בגרסאות האלה את פתיחת ה-bootloader.
- **לא לעשות downgrade לגרסה ישנה.** משתמש בפורום ניסה לחזור מ-1.1.2 ל-1.0.7 עם format מלא, והטלפון נהרס לגמרי.
- **לא לעדכן את הטלפון** (OTA של Qin) עד שהגיבוי מוכן, כי עדכון עלול לחסום עוד.

## 2. אפשרויות מפתחים
1. הגדרות ← אודות ← ללחוץ 7 פעמים על "מספר Build".
2. הגדרות ← מערכת ← אפשרויות מפתחים:
   - **"ביטול נעילת OEM" (OEM unlocking):** האפשרות קיימת? אפשר להפעיל אותה, או שהיא אפורה? **רק לבדוק, לא להפעיל עדיין.**
   - "ניפוי באגים ב-USB": מופעל (כבר מופעל בשביל ADB).

## 3. מידע נוסף
- הגדרות ← אודות ← **גרסת Baseband** ו**גרסת Kernel**: לרשום.
- הגדרות ← אודות ← **תיקון אבטחה (Security patch)**: לרשום את התאריך.
- הגדרות ← אודות ← **סטטוס ← IMEI**: לצלם מסך ולשמור במקום בטוח (לא בצ'אט). אם הגיבוי נכשל, צריך את זה כדי להוכיח מה היה.
- כרטיס SIM: באיזה ספק? האם יש **VoLTE** (סמל HD / 4G בזמן שיחה)?

## 4. לפני שמחברים לסקריפטים
- סוללה מעל 60%.
- כבל USB מקורי או איכותי, בלי מפצל.
- **ה-phone.lock אצל הצ'אט שמריץ** (צ'אט הבדיקות משחרר אותו קודם).
- דיסק עם 20GB פנויים שהוא לא C, ועוד דיסק/USB לעותק השני של הגיבוי.

## סדר ההרצה (ר' README.md)
`00_device_info.sh` ← `01_backup_critical.sh` (חובה, ושני עותקים) ← `02_dump_partitions.sh` ← `03_extract_blobs.sh` (בלי טלפון).
אף סקריפט לא כותב לטלפון, לא פותח bootloader ולא צורב.
