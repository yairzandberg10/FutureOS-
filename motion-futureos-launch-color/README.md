# סרטון ההשקה של FutureOS: הגרסה לאינסטגרם

עותק של `motion-futureos-launch`, בגודל של אינסטגרם: ‏1080×1920 (9:16, לרילס ולסטוריז). אותו תסריט, אותם זמנים ואותו פס קול. מה שונה:

1. **מסך הבית הוא הלאנצ'ר המקורי** (FutureLauncher). רשת של 4×4 עם האייקונים האמיתיים של האפליקציות, בלי שום שינוי באיור. הפוקוס הוא מסגרת בצבע ההדגשה, והאייקון גדל ב-15% כמו במכשיר. מתחת יש רקע ומעל שורת המצב. השורות פרוסות עד הנקודות של העמודים, כדי שלא יישאר רווח ריק למטה.
2. **השרטוט והאפליקציות רגילים, עם צבע ההדגשה:**
   - **השרטוט:** קווים לבנים, והמידות בצבע ההדגשה.
   - **האפליקציות:** כמו במערכת, והצבע היחיד בהן הוא צבע ההדגשה. בהודעות יש עיגול אפור עם ראשי תיבות, כמו ברשימת השיחות האמיתית.
3. **צבע במקומות אחרים:**
   - **צבע הדגשה:** תכלת מההתחלה.
   - **הכיתובים:** השורה השנייה בצבע.
   - **"בצבע שלך":** כל בחירה מציפה את כל הפריים.
   - **הטלפון:** אור תכלת וכתום על הקצוות ועל הגב.
   - **הסיום:** האותיות של FutureOS נוחתות בצבע.
4. **הפריים האנכי:** הכיתובים למעלה (מתחת ל-250 הפיקסלים של אינסטגרם), והטלפון מתחתם. בסצנה של "כל מה שצריך" הרשימה המחוקה משמאל והטלפון מימין.

הסרטון המקורי (16:9, שחור לבן) נשאר בתיקייה `motion-futureos-launch` בלי שינוי.

## מה יש כאן

| קובץ | מה בו |
|---|---|
| `make-assets.py` | מכין את `assets/`: האייקונים של האפליקציות מהריפו (החזית של האייקון על הרקע שלו, חתוכים לאזור שהמערכת מציגה) ואת הרקע |
| `fos-data.js` | המידות של דגם Regular מתוך `hardware/openscad/futureos_family.scad`, הטוקנים מהדיזיין סיסטם, הלוגו, הטקסטים ו-16 האפליקציות של מסך הבית |
| `fos-timeline.js` | לוח הזמנים של כל הסרט |
| `fos-phone.js` | הגוף בתלת ממד (three.js), כולל האור הצבעוני |
| `fos-ui.js` | המסכים (640×960): הלאנצ'ר, האפליקציות ומסגרת המיקוד |
| `fos-overlay.js` | קווי השרטוט, המידות, היד, האייקונים שנמחקים והלוגו |
| `scene.js` | המצלמה (מכוונת לפריים האנכי), הכיתובים, הצבע שמציף את הפריים והסאונד |
| `bed.py` | פס הקול המסונתז (120 BPM). יוצר את `bed.wav` |

## פקודות

```bash
python make-assets.py         # האייקונים והרקע (כבר נמצאים ב-assets/)
python bed.py                 # פס הקול
python render.py check        # בדיקה אוטומטית של הטקסט והתנועה, עם השוליים של אינסטגרם
python render.py preview      # טיוטה בחצי גודל: out/preview.mp4
python render.py full         # הסרטון הסופי: out/final.mp4
```

הפייתון הוא זה של `~/.motion-studio/venv`. אם הדפדפן של Playwright לא מותקן, `render.py` משתמש ב-Chrome שמותקן במחשב. בכרטיס מסך חלש, `GL=swiftshader` מרנדר את התלת ממד בלי כרטיס המסך.
