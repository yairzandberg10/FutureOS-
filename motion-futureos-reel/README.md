# ריל של FutureOS לאינסטגרם

סרטון של 33.5 שניות, ‏1080×1920 (9:16, לרילס ולסטוריז), ‏30fps, עם פס קול. **זו עריכה של סרטון ההשקה**, לא סרטון נפרד: הגוף התלת ממדי, המסכים, קווי השרטוט והיד הם אלה של `motion-futureos-launch-color`, בלי ציור מחדש. הריל רק בוחר מה מהסרטון מנגן, איפה ובאיזו מהירות.

## למה זה נראה כמו המכשיר

- **החומרה:** דגם Regular בתלת ממד (three.js), נבנה מהמספרים של `hardware/openscad/futureos_family.scad`: ‏53 × 145.3 × 8 מ"מ, מסך 2:3 עם חור מצלמה, כפתורי הפונקציה, ה-D-pad עם OK, מקלדת T9 עם הסימונים העבריים והלטיניים, כפתורי הצד והגב.
- **התוכנה:** המסכים ב-640×960 המקוריים, מהדיזיין סיסטם: FutureLauncher עם אייקוני האפליקציות עצמם (בלי שינוי), הודעות, ניווט, ספריית "בלכתך בדרך", עוזרי, צבע הדגשה. מסגרת מיקוד אחת עוברת בין כולם, כמו במכשיר.
- אין כאן שום מסך שצויר בשביל הסרטון ושום גוף שאינו הדגם.

## רשימת החיתוכים

ב-`reel-edit.js`: כל שורה היא `[תחילת הריל, סוף הריל, תחילה בסרטון המקורי, מהירות]`. החיתוכים על רשת ה-120 BPM (חצי שנייה = 15 פריימים), וב-x2 לחיצה על רבע פעימה בסרטון המקורי נופלת על 16-ית בריל. החיתוך נופל חצי פריים מוקדם, כדי שתת-הפריימים של מריחת התנועה לא יתערבבו בין שני שוטים.

## פס הקול

`bed.py` מסונתז מאפס (120 BPM, בלי דגימות). הסקציות שלו נקראות מרשימת החיתוכים, אז שינוי בעריכה מזיז גם את המוזיקה: הדרופ על מילוי הגוף, נשימה בזמן הקוד, ריזר לפני הסיבוב, מכה ואקורד על הסימן. כל לחיצת מקש ב-`fos-timeline.js` נשמעת כקליק באותו פריים שבו המקש שוקע.

## פקודות

```bash
python bed.py                 # פס הקול: bed.wav
python render.py check        # בדיקה אוטומטית: טקסט, זמני קריאה, שוליים של אינסטגרם, פריימים קפואים
python render.py stills T1 T2 # פריימים בגודל מלא + stills/sheet.jpg
python render.py preview      # טיוטה בחצי גודל: out/preview.mp4
python render.py flashcheck   # בדיקת הבהובים
python render.py full         # הסרטון הסופי: out/final.mp4 (SUB=4: מריחת תנועה)
```

בכרטיס מסך חלש או בלי כרטיס מסך: `GL=swiftshader`. הצנרת דורשת Python עם `playwright`, ‏`numpy`, ‏`pillow` ו-`imageio-ffmpeg` (או ffmpeg במערכת).

## הערה על בדיקת ההבהובים

`flashcheck` סופר כל פריים שבו הבהירות עולה ביותר מ-2 נקודות. גל הצבע ("בצבע שלך") עולה בהדרגה על פני כמה פריימים, אז הוא נספר כמה פעמים, גם בסרטון המקורי (ב-60fps). זו עלייה אחת ואחר כך שקט, לא הבהוב חוזר. הגלים בריל במרווח של שנייה אחד מהשני, במהירות של הסרטון המקורי.
