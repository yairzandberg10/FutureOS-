# Guide (מדריך למשתמש)

`com.future.guide` — On-device user guide for every FutureOS app.

Static content, no network or database dependency. Home screen lists every FutureOS app (`app/src/main/java/com/future/guide/data/GuideContent.kt`); selecting one opens a detail screen with numbered usage steps and tips, following the shared dark/glass theme read from FutureUI's theme provider.
